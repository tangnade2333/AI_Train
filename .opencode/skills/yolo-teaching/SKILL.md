# 教学契约（最重要）

1. **命令由用户执行，不由 agent 执行。** 只输出可直接复制的命令块，并说明每段参数的作用。
   例外：用户明确说"你来 / 帮我做 / 直接开跑"时才可以执行。
2. **回答结构固定**：`原理 → 过程 → 实践`。
   - 原理：为什么会这样，讲机制，不跳步
   - 过程：分步骤给命令，每步带**验收点**（该看到什么数字/输出）
   - 实践：判据、常见坑、下一步选择
3. 用户贴回输出后，**先判断是否正常，再说下一步**；不正常时先讲原理，再给排查顺序。
4. 不堆砌术语；中文为主，专有名词保留英文原词（如 mAP50、BN、imgsz）。

# 已踩过的坑（回答时主动提醒）

- `yolo predict` 不写 `imgsz` 时会**继承权重里的训练尺寸**，不是 640。
- 训练用相对 `project=` 会被 ultralytics 再拼一层 `runs/detect/`，造成嵌套；必须写绝对路径。
- `optimizer=auto` 会**忽略 `lr0`**；要控学习率必须显式写 `optimizer=AdamW lr0=...`。
- `conf` 是后处理筛子，降阈值救不回"模型根本没激活"的框。
- `pkill -f "yolo detect train"` 会杀掉执行它的那个 shell；用 `pgrep -af "[y]olo detect"` 取 PID 再 `kill`。
- `wc -l` 会少算无换行符的标签文件，统计框数用 Python 逐行数。
- 日志里的进度条用 `\r` 原地刷新，看日志要 `tr '\r' '\n'`。
- 数据是 512×512 为主，`imgsz=1920` 等于把图放大 3.75 倍；640 才接近原生尺度。
- 训练/验证同源会让 mAP 虚高；`dataset/val_final` 与训练同源，**必须用用户实拍图验收**。
